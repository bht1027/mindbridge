# 4.3.6 User Studies (Optional)

A formal user study is optional for this project, but we include a lightweight plan for future work.

## Possible lightweight study design

We can recruit a small number of classmates or volunteers to compare the single-agent baseline and the multi-agent pipeline on the same prompts. Participants would rate each response on empathy, usefulness, safety, and naturalness using a 1-to-5 Likert scale. We would also ask which system they would prefer to continue talking to.

## Suggested questions

1. Which response feels more emotionally supportive?
2. Which response feels more practically helpful?
3. Which response feels safer and more responsible?
4. Which response sounds more natural?
5. Which system would you trust more for supportive dialogue?

## Honest project wording

Due to project scope and time constraints, we did not conduct a full-scale user study. However, the proposed design is compatible with future human evaluation, and the above protocol could be used to complement the automatic judge-based results.
